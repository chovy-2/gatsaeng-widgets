# 🐈‍⬛ Gatsaeng Pixel Widgets

2027 갓생 노션 플래너용 검은 고양이 픽셀 위젯이에요. 로그인이나 개인정보 없이 브라우저 안에서만 동작해요.

- `widget.html?w=clock` : 시계 + 날짜
- `widget.html?w=dday&title=토익&date=2027-01-24` : D-day
- `widget.html?w=progress` : 올해·이번 달·이번 주·오늘 진행률
- `widget.html?w=pomo` : 포모도로 타이머 (집중 25분 · 짧은 휴식 5분 · 긴 휴식 15분)
- `widget.html?w=quote` : 오늘의 한마디 (날짜마다 바뀌는 응원 문구)
- 시계·한마디의 고양이는 시간대에 따라 바뀌어요 (아침 ☀️ / 낮 📚 / 저녁 🏮 / 밤 🌙)
- `&theme=light` : 라이트 테마

`index.html`에서 위젯을 고르고 주소를 복사해 노션 `/임베드`에 붙여넣으면 돼요.
